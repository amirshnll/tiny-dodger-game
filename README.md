# Tiny Dodger

## Short description

Dodge falling obstacles and survive as long as possible.

## Description

Tiny Dodger is a compact, multilingual arcade game for the browser. Players move left and right to avoid falling blocks, collect stars, build combos through near misses, and improve their best score and survival time.

## Purpose

The extension delivers an instantly accessible arcade challenge for short play sessions while supporting keyboard and pointer controls, sound preferences, and reduced-motion options.
